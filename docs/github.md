# Публикация в GitHub

Эта папка содержит исходный код без данных рабочей установки. Git-история автора, результаты сканов, `backups/`, `scans/`, локальные `.env`, кэши, зависимости и аварийные дампы исключены.

1. Выберите лицензию исходного кода, если хотите разрешить его использование и распространение на определённых условиях. В подготовленной папке лицензия приложения пока не назначена; лицензия шрифта приложена отдельно.
2. Создайте на GitHub пустой репозиторий. Не добавляйте README в форме создания, поскольку он уже есть здесь.
3. Откройте терминал именно в этой подготовленной папке:

```sh
git init -b main
git add .
git status --short
git diff --cached --stat
git commit -m "Initial public source release"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Замените `YOUR_USERNAME` и `YOUR_REPOSITORY` своими значениями. Для HTTPS GitHub требует токен или вход через credential helper / GitHub CLI, а не пароль аккаунта. Не сохраняйте токен в URL, `.env.example` или исходниках.

Публикуйте содержимое этой папки. Не выполняйте `git add .` из родительского рабочего каталога с реальными отчётами. Данные и резервные копии остаются в исходной установке.

Если Git попросит имя и email для коммита, настройте их для этого репозитория самостоятельно. Автор коммита и адрес удалённого репозитория здесь не подставлены.
