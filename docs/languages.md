# Русский и английский интерфейс / Russian and English interface

Переключатель **RU / EN** находится в верхней панели рядом с темой. По умолчанию выбран русский; язык сохраняется в `webscanner-language` в localStorage браузера. Выбор распространяется на вкладки того же браузера, без отдельной настройки аккаунта.

Переключение обновляет навигацию, формы, меню, подсказки, доступные названия элементов, статусы, уведомления, DNS, сравнение, карту и подписи SVG. Заполненные формы, выбранный проект, URL фильтров и состояние карты не сбрасываются. Ранее скачанный SVG не изменится: скачайте его заново на нужном языке.

Дата форматируется как `ru-RU` или `en-GB`. **Время всегда 24-часовое**, с явным `hourCycle: h23`: от `00:00` до `23:59`, без AM/PM. Часовой пояс остаётся часовым поясом браузера; выбор языка его не меняет. Время обследования при загрузке файлов вводится отдельно как `HH:mm`, чтобы системный виджет не добавлял AM/PM. В API и архивах даты остаются ISO 8601.

Имена проектов и частей сети, комментарии, авторы, хосты, баннеры, заголовки сервисов и содержимое загруженных файлов не переводятся. Технический вывод внешних инструментов сохраняется как есть. Архив проекта универсален; язык интерфейса получателя определяется его браузерной настройкой. CLI в эту локализацию не входит.

Запросы веб-интерфейса отправляют `Accept-Language`. Backend переводит известные ошибки при выборе английского и возвращает стабильное поле `code` (`invalid_request`, `not_found`, `conflict`, `validation_error`, `queue_unavailable`, `request_failed`). Старое поле `detail` сохранено. При отсутствии заголовка прежнее поведение на русском сохраняется. Исторические сообщения и предупреждения локализуются только в известных полях диагностики; пользовательские данные не обходятся переводчиком.

## Поддержка переводов

- `frontend/src/i18n/core.ts`: состояние языка, `t`, форматирование даты/времени и чисел, формы числа хостов.
- `frontend/src/i18n/en.json`: английские переводы. Русские исходные сообщения служат читаемыми ключами; переменные передаются через `{v0}`, `{v1}` и не переводятся.
- `frontend/src/i18n/api.en.json` и `backend/app/core/api.en.json`: согласованные переводы диагностических сообщений. Менять обе копии вместе.
- `frontend/src/i18n/api.ts`: язык запросов и перевод только полей диагностики.

Новые интерфейсные строки следует вызывать через `t`, оставляя пользовательские значения параметрами. Для дат используйте `formatDateTime`/`formatDate`, а не прямой `toLocaleString`. Подписи в константных таблицах должны вычисляться при чтении, чтобы реагировать на переключение языка.

```sh
node frontend/tests/i18n.cjs
PYTHONPATH=backend python3 -m unittest discover -s backend/tests
```

Проверка переводов контролирует наличие всех используемых ключей, совпадение параметров, отсутствие кириллицы в английском каталоге, 24-часовой формат, сохранение формы при смене языка, отдельное поле времени и неизменность пользовательских данных. Новых зависимостей и миграций БД нет. Для применения нужно обновить frontend и backend.

## English

Use **RU / EN** beside the theme selector. The choice is remembered in your browser. Switching languages keeps your project selection, filters and form values. Time always uses the **24-hour clock**, including midnight as `00:00`; there is no AM/PM. The browser’s time zone is unchanged. Enter report times as `HH:mm`.

Project names, comments and scan evidence stay in their original language. Download SVG again after switching languages to export its labels in English. Imported project archives do not change your language preference.
