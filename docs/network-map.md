# Многоуровневая карта по отчётам

В разделе «Карта сети» выберите отчёты, нажмите «Показать доступность», затем «Карта». Выберите начальный источник. Ветки раскрываются автоматически: если найденное устройство само является источником выбранных отчётов, карта продолжит связи из него. Кнопки +/− сворачивают ветки; общие устройства остаются одним узлом, обратные связи не создают бесконечных уровней.

Карта открывается в масштабе 100%, с начальным источником в видимой области. Между соседними уровнями оставлено 130 пикселей свободного пространства. Для полного обзора нажмите «Вместить в окно»; в этом режиме масштаб следует размеру окна. Открытие карточки устройства сохраняет масштаб и положение и отключает автоподбор. Выбор другого начального источника возвращает читаемые 100%.

Нажмите устройство: справа появятся отчёты из этого хоста и список сервисов. Выбор сервиса включает «Кто видит этот сервис?». Кнопка «Вернуться к веткам» возвращает общую схему. «Показать путь до хоста» открывает поиск пути с выбранными началом и целью.

Источник сопоставляется с устройством по IP в начале подписи (например, `10.0.0.30 · сервер`) или точному имени хоста из отчёта. Сопоставление выполняется внутри части сети. В режиме «Весь проект» интерфейс по умолчанию включает «Общую адресацию», объединяя одинаковые IP разных частей. Если адресация повторяется на независимых площадках, отключите этот параметр перед построением карты. При прямом вызове API объединение по умолчанию отключено. Произвольные подписи и неоднозначные имена автоматически не склеиваются. Несопоставленный источник доступен как начальная точка, но не продолжает ветку другого устройства.

Карта использует все выбранные отчёты. Поиск подсвечивает совпадения, сохраняя соединяющие узлы. Устройства без открытых портов также остаются на карте, если их присутствие зафиксировано в отчёте; поиск путей по сервисам требует обнаруженных портов.

Пунктир — обнаруженная доступность по отчётам, а не физический маршрут, действующий туннель или доказанный доступ для перехода. Старые и новые наблюдения сохраняют свои отчёты и даты. Для добавления новой пачки включите её в выбор и заново нажмите «Показать доступность».

## Окружение хоста и сервисы

Нажмите устройство и выберите «Показать окружение». Слева будут источники входящих наблюдений, в центре выбранное устройство, справа устройства, обнаруженные из него. Это один шаг по отчётам, не подтверждённый маршрут. Если сосед встречается и как входящий, и как исходящий, он остаётся одним узлом с обеими стрелками. Входящие источники учитываются по всем выбранным отчётам, даже если не входят в исходную ветку начального источника.

Нажатие соседнего хоста продолжает исследование его окружения. «Вся карта» возвращает исходный выбранный хост, прежние масштаб, прокрутку и состояние свёрнутых веток. Закрытие карточки тоже возвращает общий вид. Выбор начального источника сбрасывает окружение и фильтр.

В меню «Сервисы на схеме» отметьте один или несколько портов/протоколов. Карта показывает совпадения по любому из отмеченных сервисов. В списке есть поиск по порту или обнаруженному имени сервиса; активные порты показаны отдельными плашками, каждую можно убрать крестиком. Фильтр убирает посторонние ветки, сохраняя соединяющие наблюдения серыми с надписью «Контекст». Эти линии не выдаются за обнаружение выбранных сервисов. Фильтр действует на текущую ветку или окружение; для сброса выберите «Все сервисы». В режиме «Кто видит этот сервис?» используется точный сервис из карточки, поэтому общий фильтр временно отключён. Изменения только визуальные, отчёты и результаты не изменяются.

## Область карты и ограничения

В поле «Просмотр» доступны выбранная часть сети и весь проект. Место сохранения новых сканов и импортов задаётся отдельно верхней панелью. Смена области просмотра не переносит отчёты.

Выбираются до 50 отчётов одного проекта. API допускает не более 50000 записей портов в выбранных отчётах и 5000 уникальных строк матрицы, включая присутствие хостов. Таблица разбита по 100 строк. Лимита в 80 устройств на карте нет; свёрнутые ветки и фильтры ограничивают видимые узлы.

«Развернуть» открывает карту поверх страницы, Esc возвращает обычный вид. Доступны масштаб кнопками и Ctrl + колесо, перемещение по свободному полю, подгонка в окно и сброс масштаба.

node frontend/tests/mapExploration.cjs
