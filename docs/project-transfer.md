# SVG и перенос проектов

## Перед применением

Перед обновлением сохраните PostgreSQL и каталог `scans/`. Локальные резервные копии автора в репозиторий не включены.

На хосте дождитесь завершения сканов и DNS-задач, не запускайте новые до окончания копирования:

```sh
./scripts/backup_before_project_transfer.sh
```

Скрипт сохраняет PostgreSQL в custom-формате, проверяет оглавление дампа, архивирует код и `scans/`, проверяет архив и записывает SHA-256. При ошибке не сообщает об успешном завершении.

После успешной резервной копии примените код:

```sh
docker compose up --build -d
```

Миграция 9 добавляет nullable-поля `projects.description` и `projects.map_view`, существующие данные не удаляются. Сохраняйте прежнее имя Compose-проекта и volume базы. Новых зависимостей не добавлено. Перед запуском сканов дождитесь готовности backend и worker.

## SVG

На странице «Карта сети» постройте карту и откройте «Экспорт SVG» в панели над схемой:

- **Текущий вид**: всё полотно текущего режима, включая области за пределами окна. Сохраняются фильтры, свёрнутые ветки, выделение и оформление. Размер не зависит от экранного масштаба. Метаданные отчётов и настроек записываются в SVG `desc`.
- **Вся карта**: все устройства выбранных отчётов, включая отдельные компоненты и устройства без связей. Ветки раскрыты, фильтры интерфейса не применяются. Экспорт имеет собственную раскладку, светлый фон, подписи источников и список отчётов с датами и авторами.

SVG открывается в браузере и масштабируется без потери чёткости. Файл статический: раскрытие веток и панели приложения в нём не работают. SVG отражает выбранные отчёты, а не автоматически все отчёты проекта. Для охвата всего проекта выберите соответствующий просмотр и нужные отчёты; существующий лимит построения карты — 50 отчётов.

## Архив проекта

В меню «Управление проектом» доступны действия «Экспорт проекта» и «Импорт проекта». Выгрузка охватывает весь выбранный проект, независимо от выбранной части сети и отчётов карты.

Действие «Описание проекта» в том же меню открывает диалог: в нём можно записать цель обследования и выводы. Кнопка сохранения запоминает описание, выбранные отчёты построенной карты, источник, часть сети и режим адресации. Если карта не построена, ранее сохранённые настройки остаются. Масштаб, свёрнутые ветки, фильтры сервисов и боковая панель не сохраняются. «Открыть сохранённую карту» восстанавливает подготовленный набор отчётов и источник.

Архив содержит версионированный `manifest.json`, контрольные суммы SHA-256, `project.json`, `README.txt` и файлы сканов. Переносятся части сети и их настройки DNS, параметры и статусы сканов, даты, комментарии, источники, авторы, область проверки и исключения, DNS-результаты, хосты, порты, сервисы, скриншоты и исходные файлы. Связи повторных запусков внутри проекта сохраняются; ссылки на сканы вне проекта очищаются.

Экспорт активных сканов или DNS-задач отклоняется. Импорт показывает состав и предлагает название, после чего создаёт отдельный проект с новыми ID. Совпавшее название нужно изменить. Автоматического объединения и перезаписи существующих проектов нет; никакие сетевые задачи при импорте не запускаются.

Лимиты: 512 МБ для загруженного архива и распакованных данных, 20000 файловых записей. Проверяются версия, контрольные суммы, структура, связи и пути; символические ссылки и выход из каталога запрещены. При обычной ошибке импорта изменения БД откатываются, созданные каталоги удаляются. Импорт большого проекта может занять некоторое время. ZIP содержит исходные сведения обследования и скриншоты, без шифрования.

## Проверка и откат

```sh
PYTHONPATH=backend python3 -m unittest discover -s backend/tests
python3 scripts/check_retry_api.py
for testfile in frontend/tests/*.cjs; do node "$testfile" || exit 1; done
```

Перед откатом остановите активные задачи. Предыдущий код может работать с добавленными nullable-колонками: для отката только кода возвращайте файлы из резервной копии и пересобирайте сервисы. Полное восстановление PostgreSQL из дампа заменяет состояние базы; выполняйте его отдельно в остановленной установке, вместе с соответствующим `scans/`. Не используйте `docker compose down -v` для обновления или отката кода.
