# SMB: хосты, доступ и файлы

В карточке основного скана откройте **SMB**. Работа идёт в одном окне:
слева — хосты и шары, справа — папки, предпросмотр или результаты поиска.

## Быстрый старт

1. Хосты с открытым **TCP 445** уже добавлены слева со статусом «Не проверено».
2. Нажмите **«Проверить доступ»**, выберите вход без учётки, пароль Windows,
   NT/LM:NT-хэш или Kerberos AES-ключ и запустите проверку. Исходная подсеть
   целиком повторно не подставляется; без подтверждённых TCP 445 предлагаются
   сохранённые IP основного скана. Цели можно изменить в настройках.
3. В таблице появятся шары и метки READ/WRITE. По умолчанию показаны доступные
   файловые шары; остальные результаты доступны через фильтр. Непроверенные
   хосты остаются видны, пока для них не получен результат.
4. Нажмите IP/шару — папки откроются справа. Одно нажатие на файл выбирает его
   и загружает предпросмотр ниже списка; там же скачивание и проверка прав.
5. Для поиска по сети нажмите **«Собрать список файлов»** рядом со строкой поиска.
   Сохранённые списки обновляются, активный поиск повторяется по мере их поступления.

## Одна учётка для текущей работы

Сверху всегда видна текущая учётка. Кнопка учётки открывает единую форму подключения;
пароль отображается открытым текстом. В файловом менеджере отдельной формы входа нет.
Повторная проверка доступа и сбор списков используют действующее подключение без
повторного ввода секрета. При отсутствии подключения будет раскрыта форма сверху.
Для уже найденной шары можно подключиться без повторного сканирования сети.

Сохранённые результаты и текущая учётка — разные вещи. Слева фильтр
**«Результаты проверки»** выбирает сохранённую учётку; это не переключает подключение.
В заголовке открытой шары указано, под кем получен результат. Чтение файлов и проверка
их прав идут под текущей учёткой сверху, не под автором исторического результата.
Переключение шары сохраняет последнюю папку, страницу, фильтр, выделение и прокрутку
в памяти текущего SMB-раздела (до 20 шар). Отдельных вкладок нет.

Подключение действует 15 минут. В tab sessionStorage сохраняются только capability-токен,
область действия и исходный срок; пароль/хэш/AES-ключ не сохраняются в браузере.
Перезагрузка восстанавливает оставшийся срок, не продлевая его. Учётные данные находятся
во временной Redis-сессии; задания и архивы не содержат секретов. Секреты не передаются
в argv процессов. Отключение отзывает текущий токен. Защита Redis и транспорта зависит
от настройки установки. Пароль/NTLM-подключение может охватывать сохранённые хосты
текущего скана; Kerberos сохраняет явную область IP/SPN. Для сканирования используется
отдельный одноразовый ключ учётных данных. `.ccache` пока не поддерживается.

## Поиск и чтение файлов

Общий поиск справа ищет только **сохранённые имена и пути**, не содержимое документов.
Введите `договор`, `pass`, `*.kdbx` или `HR/*.docx`, затем Enter/«Найти». Обычный текст
ищется как часть пути без учёта регистра; `*` и `?` — маски, остальные символы буквальные.
`passwd` и `password` — разные строки; `pass` подходит для обеих.

Для каждой пары хост/учётка/способ входа берётся последний результат. Старые списки
не подмешиваются, если новая проверка собирала только шары. Одинаковые хост/шара/путь
объединяются; кнопки учёток сохраняют источники. Совпадение пути не гарантирует
одинаковое содержимое. Размер берётся из самого свежего совпадения. Нажмите файл
для открытия справа, учётку — для выбора её исторического источника. **«К результатам»**
возвращает к тому же запросу и странице; список шар остаётся слева.

Счётчик списков показывает хосты, для которых был сбор файлов или импорт spider_plus,
а не гарантированно полный обход. Глубина, лимиты и ошибки могут ограничивать результаты;
это отмечается предупреждением. Отсутствие файла не означает отказ в доступе.
Фильтр внутри файлового менеджера относится **только к текущей папке**, без рекурсии.

Предпросмотр: текст/конфиги/скрипты/CSV/JSON/XML/HTML, DOCX и XLSX (до первых трёх листов,
без вычисления формул), не более 60000 символов. Для PDF, старых DOC/XLS и изображений —
скачивание. Файлы ограничены 20 МиБ. Поиск секретов в текстовых файлах доступен отдельным разделом;
массового скачивания папок и ZIP папки пока нет.

## История и удаление

В **«⋯»** находятся **«История и удаление»**, импорт JSON и настройки проверки.
В истории отметьте строки или «Выбрать все», затем «Удалить выбранные» и подтвердите
количество. Удаляются локальные SMB-отчёты, оригинальные JSON и каталоги файлов.
Основной скан и файлы на компьютерах остаются. Активную SMB-проверку сначала остановите.
Удалённая открытая шара закрывается; отмены удаления нет. При необходимости заранее
скачайте JSON или архив проекта.

Импорт NetExec spider_plus — дополнительный способ загрузить исторические метаданные,
не документы. Он не подтверждает текущий доступ. Формат ограничен 20 МиБ, 100000 файлов
и 200000 записей с папками. [Синтетический пример](smb-example.json).

## Ограничения и проверки

- Активная проверка выполняется worker: до 256 целей, 15 минут на запуск, 60 секунд на хост.
  Автоматически предлагаются первые 256 найденных IP; остальные можно выбрать отдельным запуском.
- Быстрая проверка TCP 445 предшествует SMB-входу; после ошибки учётки дальнейшие попытки
  останавливаются. Анонимный вход может быть отображён сервером в гостевую учётку.
- READ проверяется листингом, WRITE — открытием существующего объекта с маской доступа.
  Файлы не создаются, не изменяются и не удаляются; ACL не меняется. Права файла
  проверяются отдельно, не выводятся из прав шары. Это не полный дамп DACL.
- Живой листинг: страницы по 100, предел 10000 записей папки. Ссылки/junction блокируются.
- Общий поиск: до 50000 совпадений до объединения и 10 секунд обработки каталогов;
  страницы по 100. При ограничении результат явно неполный. Временный SQLite
  объединения метаданных удаляется после запроса; индекс содержимого не создаётся.
- Быстрый сбор из действующего подключения: глубина 3, до 10000 записей на хост,
  только разрешённые сессии IP. «Обновить файлы хоста» обновляет каталоги всего хоста.
- Сохранённые каталоги и JSON входят в архив проекта. Живые загрузки туда не входят:
  временные файлы лежат в `scans/.smb-actions/`, успешная загрузка удаляет свой файл.
  Состояние действий истекает через 10 минут; последующие запросы убирают старые
  артефакты. Точное время физического удаления не гарантируется.
- Нужны миграция 11, согласованные backend/worker и зависимости. Команды SMB
  `ls`, `cd`, `cat`, `get`, `rights`, `pwd`, `help` доступны как дополнительный инструмент;
  произвольный shell не исполняется. Клавиши: ↑↓, Enter, Backspace, F3/F5, Ctrl+S.

## English

SMB is a single workbench: hosts/shares stay on the left, file browsing and network-wide
saved-name/path search occupy the right. Open TCP 445 hosts appear before enumeration.
Use **Check access**, one central credential form, then click a share. The top identity
is used for live reads; the saved-result identity remains explicitly labelled and
independently filterable. No duplicate login form appears inside the file browser.
Passwords remain visible while typing. Access rechecks and file-list collection reuse
the current scoped 15-minute session; expired connections must be restored.

File preview appears below the file list. Returning to a share restores its last
folder/page/filter/selection/scroll within this SMB view (up to 20 locations).
Search results occupy the right area, and Back to results preserves query/page.
Search uses latest saved reports per host/account/authentication method, merges matching
paths with clickable source evidence and never reads document contents automatically.
Partial coverage is explicit. A missing file is not proof of denied access.

History, local result deletion, optional NetExec JSON import and settings are under
**⋯**. Selected result deletion requires confirmation and does not change the main scan
or remote files. Active inventory blocks deletion. Password, NTLM and explicit Kerberos
AES/SPN/KDC authentication are supported; no `.ccache`. Preview supports bounded text,
DOCX/XLSX; other formats are download-only. Limits: 256 scan targets, 15 minutes per
inventory, 60 seconds per host/file operation, 20 MiB per file, 60000 preview characters,
100-row pages and 10000 live directory entries. Search is bounded to 50000 pre-merge hits
and 10 seconds of catalog processing. Whole-folder downloads and full DACL dumps are not implemented;
text/config secret search is available on a separate page.

Отдельный раздел «Поиск секретов» открывается кнопкой в заголовке шары. [Описание первой версии и её ограничений](secrets.md). Обычный поиск SMB по именам и путям остаётся самостоятельным действием.
