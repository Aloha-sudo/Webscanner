# UDP-сканирование

В форме нового скана выберите протокол **UDP**, затем профиль:

- **Основные UDP** (`udp_quick`) — небольшой список распространённых служб.
- **Топ 100 UDP** (`udp_top100`) — рейтинг UDP из установленной базы Nmap, независимо от TCP.
- **Свои UDP-порты** (`udp_custom`) — список или диапазон в поле портов.

API использует эти значения в `scan_type`; для `udp_custom` обязательно поле `ports`. CLI принимает те же значения в `--profile`. Миграция базы данных не требуется.

UDP запускается через Nmap отдельно от RustScan и TCP-проверок. Поддерживаются исключения адресов, имён и портов, отмена и повтор запуска. Определение PTR-имён использует существующие настройки DNS. HTTP-проверки и скриншоты в UDP-режиме не запускаются.

Лимиты: 256 целевых IPv4-адресов после исключений, 1000 выбранных портов после исключений, 1800 секунд на процесс Nmap по умолчанию (`UDP_TIMEOUT`). Превышение времени завершает запуск ошибкой, а не успешным пустым отчётом. Исходный XML сохраняется в каталоге скана, если Nmap успел его записать. Для UDP Nmap нужны права на отправку raw-пакетов.

## Интерпретация результатов

`open` — открытый порт подтверждён ответом. `open|filtered` — ответа нет: порт может быть открыт или трафик фильтруется. Предполагаемое имя службы по номеру порта не подтверждает её наличие.

Оба состояния сохраняются при импорте и экспорте и отображаются в карточке хоста. В матрице `open|filtered` обозначается как «Неопределённо». Оно не создаёт подтверждённую связь сервиса на карте; хост с одними неопределёнными портами также не считается подтверждённо обнаруженным устройством. Счётчики хостов и портов отчёта включают неопределённые записи; счётчик сервисов учитывает только `open` с именем службы.

Nmap может группировать молчащие порты в `extraports`. Программа восстанавливает записи по указанным номерам или однозначной области проверки. Если конкретные UDP-порты определить нельзя, обработка выдаёт ошибку вместо потери результатов. Причины ответов остаются в исходном XML.

UDP работает через прямое подключение. Результаты внешних обследований можно импортировать в программу.
